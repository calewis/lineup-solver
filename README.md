# Greyhounds Lineup Solver

Builds a substitution schedule for an 8-a-side youth soccer team: two 25-minute halves, subs at 6:00, 12:00 and 18:00, everyone plays 5 of 8 segments, nobody sits twice in a row, and players keep their position while on the field.

Runs entirely in the browser. Saved setups are stored in your browser's local storage.

## Development

```
npm install
npm run dev
```

Pushing to `main` deploys to GitHub Pages via the workflow in `.github/workflows/deploy.yml`.
